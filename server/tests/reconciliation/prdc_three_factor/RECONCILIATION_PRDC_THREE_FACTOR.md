# 3因子 PRDC（コールなし）の照合：相関感応度・クロスガンマ・Vanna・シナリオ損益

- 照合日：2026-11-24（`results/session_info.txt`）
- 対象：第15章の3因子 PRDC（コールなし）の API。`/api/prdc-three-factor`（表）、`/scan`（グラフと接線）、`/scenario`（1点のシナリオ）、`/scenario-curve`（縦線をドラッグするグラフ）、`/heatmap`（ヒートマップ）、`/api/cross-term-example`（為替ヘッジなし外債の例）
- 照合する側：API が実際に使う `server/R/prdc_three_factor_model.R`（rmql 0.5.0、`second_order = TRUE`）をそのまま読み込んで比べる
- 比べる相手：PV だけの有限差分（バンプ幅を数通り）、API どうし（同じ入力に同じ値が出るか）、基準値（`server/tests/golden/prdc_three_factor_golden.json`）
- 再実行：`npm run reconcile:prdc-three-factor`（基準値と `results/` を書き直す）、`npm test`（`tests/prdcThreeFactor.api.test.ts`）
- rmql 側の検査（2階自動微分と PV の4点差分の整合、既存値の不変）は、rmql の `docs/spec_prdc.md` 15 章と `tests/testthat/test-prdc.R`。

## 入力

Coral-Book に対応する R の例はない（Studio の第15章で足した画面）。第15章の PRDC と同じノート（想定元本 1億円、5年、年1回のクーポン min(8%, max(0, 2% + 80% × (S / 150 − 1)))、満期に元本を償還）、円 1.0%〜1.8%・外貨 4.0%〜3.2% の各年の金利（`server/R/prdc_risk_model.R`）、FX スポット 150、FX ボラ 12%、Hull–White（円 a 0.03・σ 1%、外貨 a 0.05・σ 1.2%）、相関 (0.3, −0.2, 0.4)。シナリオの初期値は、スポット +5 円、ボラ +2 ポイント、円金利 +20bp、外貨金利 −20bp。

読み取り：

- **相関（中心差分）**：誤差は幅の2乗で小さくなる（幅 0.1 で 8e−5〜1e−3、0.01 で 8e−7〜1e−5、0.001 で 8e−9〜1e−7）。幅 1e−4 以下は丸め誤差で 1e−10〜1e−8 に頭打ちになる。安定するのは 1e−5〜1e−3。
- **クロスガンマ・Vanna（4点差分）**：誤差の下限はスポットの幅で決まる（1.5 円で約 1e−3、0.15 円で約 1.5e−5、0.015 円で約 1e−7）。相手の幅が大きいと打ち切り誤差（金利 1e−2、ボラ 1e−2 で 1e−2〜6e−4）、小さすぎると丸め誤差（スポット 0.0015 円で相手 1e−6 のとき 3.6e−6）が出る。安定するのは、スポット 0.015〜0.15 円、金利 1e−5〜1e−4、ボラ 1e−4〜1e−5。

**ページの幅**：安定する範囲の中で、最も精度の高いものに決めた（`P3_BUMP`）。2階自動微分には、バンプ幅がない。

## 検査（`tests/prdcThreeFactor.api.test.ts`、11件）【実行照合済み】

1. **変化幅がすべてゼロなら損益はゼロ**：シナリオとドラッグ用の曲線（スポット 0 円の点）で、三つの損益、二つの差、七つの寄与がゼロ（1e−6 円未満）。**スポットだけを動かした場合は、交差項の寄与がゼロ**（シナリオ、曲線の全点）。ヒートマップでは、ボラの変化がゼロの行とスポットの変化がゼロの列で、Vanna がゼロ。
2. **単点シナリオと曲線・ヒートマップの一致**：同じショックで、フル再評価、一次近似、一次＋交差項、二つの差、交差項の寄与（円金利・外貨金利・Vanna）が一致（スポット −30、−10、0、+5、+30 円。ヒートマップはボラ・円金利・外貨金利の3つのセル）。バブルの縮尺は、曲線の全点の交差項の絶対値の最大に等しい。
3. **接線の傾きと感応度表の値が単位まで一致**：相関（+0.01 あたり）、クロスガンマ2種（FX 1円 × 1bp あたり）、Vanna（FX 1円 × ボラ 1 ポイントあたり。デルタをボラで見た傾きと、ベガをスポットで見た傾きの二つとも）。接線はその点の値を通る（相関の接線は PV、金利のシフトなしの接線はデルタ、ボラ 12% の接線はデルタ、スポット 150 の接線はベガ）。
4. **自動微分と有限差分**：ページの幅で、相関は相対 1e−6、クロスガンマ・Vanna は 2e−6 以内。
5. **基準値との回帰**：PV、グリークス、感応度表、接線の傾き、シナリオ、曲線の点、バブルの縮尺が基準値（相対 1e−9）と一致。為替ヘッジなし外債の例（−2.0 + 5.0 + (−0.1) = +2.9）と、任意の入力で合計が三つの和になること。
6. **不正な入力**：範囲外の相関、相関行列にならない組み合わせ、未知の項目、範囲外のショックが、メッセージつきで 400 になる（5つの API）。

基準値の1つを相対 1e−5 動かすと、検査 5 が落ちることを確認した。

## 範囲と限界

- 外部の基準値はない（QuantLib v1.42 に3因子の FX・金利モデルがない）。自動微分と有限差分の一致は、**同じ rmql の閉じた式の自己整合**であり、モデルそのものの検証ではない。モデルの検査は rmql 側（`docs/spec_prdc.md` 5〜7 章、15 章）。
- シナリオの「近似との差」には、交差項に入れていない項（スポットのガンマ、ボラの二階、金利どうし・金利とボラの交差、3次以上）が入る。これらの2階微分は rmql にまだない。
- ヒートマップとグラフの格子は表示用に粗い（ヒートマップ 112 セル、曲線 81 点）。格子の細かさによる誤差の評価はしていない。
- コール、ターゲット償還、ノックアウトはない（`second_order` は閉じた式だけ）。

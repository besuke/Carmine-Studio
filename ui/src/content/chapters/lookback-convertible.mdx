# ルックバック・転換社債・MSCB

ルックバック・オプション、転換社債、転換価額修正条項つき転換社債（MSCB）の価値とグリークスを、条件を動かして確かめます。

## ルックバック

変動ストライクは、満期までの最小値（最大値）が行使価格になります。連続監視は閉じた式、離散監視は木で求めます。

## 転換社債

転換すれば転換価値、しなければクーポンと償還額を受け取ります。信用スプレッドは、転換されない部分にだけかかります。

## 転換時にリセットする MSCB

転換価額は転換時の株価の $\alpha$ 倍（下限・上限で切り取り）。転換で受け取る価値は
$F\,\max\bigl(S/K_{\max},\ \min(S/K_{\min},\ 1/\alpha)\bigr)$ です。

## 転換価額を持ち越す MSCB

リセット日の株価で転換価額を見直し、次のリセット日まで持ち越します。限度がなければ $S/K$ の 1 次元に縮約できます。

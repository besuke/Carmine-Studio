# CNNによるモデルキャリブレーションと近似の設計（Hull–White・MBS・CLO）

重い金融モデルを CNN で近似するときの設計の要点である。

- **入力の形**：並びに構造がある入力（時系列、満期×ストライクの格子）は、1D・2D の畳み込みで扱う。
- **教師データ**：厳密な評価から作る。
- **検証**：学習範囲の内側と外側を分けて誤差を測る。
- **フォールバック**：範囲外や無裁定の条件違反は、厳密な計算へ戻す。
- **感応度**：近似した関数の微分は、元の関数の微分より誤差が大きくなりやすい。精度が要る感応度は自動微分で求める。

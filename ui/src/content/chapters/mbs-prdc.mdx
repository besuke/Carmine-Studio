# MBS・PRDC

MBS の元本残高と、TARN・ノックアウトつき PRDC の累積クーポンを、経路ごとに持ち越して評価します。PRDC の基本の評価は、PRDC の画面で操作できます。

## MBS：期限前返済と残高

借換え金利の動きで返済の速さが変わり、残高の経路が変わります。借換え金利の傾きを変えて、価格と平均残存期間を比べます。

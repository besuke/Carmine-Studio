# rmql への依頼：コールなし3因子 PRDC の2階感応度（クロスガンマ・Vanna）

- 依頼元：Carmine-Studio 第15章「PRDCグリークス計算（自動微分・有限差分）」（`ui/src/content/chapters/automatic-differentiation.mdx` の節「3因子 PRDC の相関感応度・クロスガンマ・Vanna」）
- 依頼日：2026-11-25
- 宛先：RiemannQL（rmql）の会話。Studio は計算を自分で書かず、rmql を呼ぶ（Studio の `CLAUDE.md`）。

## 1. 依頼

`compute_prdc_three_factor_value()` のコールなしの閉じた式（`docs/spec_prdc.md` 5 章・7 章）に、次の2階感応度を足し、R の戻り値から取れるようにする。

| 名前 | 定義 | 表示単位（Studio が掛けて表示する） |
|---|---|---|
| クロスガンマ（FXスポット × 円金利） | `∂²NPV / ∂S ∂r_d`。`r_d` は円（国内）カーブの連続複利ゼロ金利の**平行シフト**（小数、+0.0001 が 1bp） | FX 1円 × 金利 1bp あたり（`× 1e-4`） |
| クロスガンマ（FXスポット × 外貨金利） | `∂²NPV / ∂S ∂r_f`。`r_f` は外貨カーブの同じ平行シフト | 同上 |
| Vanna（FXスポット × FXボラティリティ） | `∂²NPV / ∂S ∂σ_X`。`σ_X` は FX ボラティリティ（小数、0.12 が 12%） | FX 1円 × ボラティリティ 1ポイントあたり（`× 0.01`） |

- 値は、1階の感応度と同じく、**2階自動微分**（閉じた式を `Operand` について総称的に書いた式の上での2階）で求める。差分ではない。
- rmql の戻り値は、小数・1円・カーブの平行シフトの単位のままでよい。単位の換算は Studio が行う。
- 範囲：コールなし、ターゲット償還なし、ノックアウトなしの閉じた式だけ（`paths = 0`）。モンテカルロやコール付きは対象外。

## 2. 戻り値の形（案）

`compute_prdc_three_factor_value()` に引数 `second_order = FALSE` を足す。`TRUE` のとき、戻り値に tibble `second_order` を足す。

| 列 | 内容 |
|---|---|
| `parameter_1`、`parameter_2` | `"spot"` と `"domestic_curve_shift"`、`"spot"` と `"foreign_curve_shift"`、`"spot"` と `"fx_volatility"` |
| `d2_npv` | 2階の交差微分（上の単位） |

- 既定の `FALSE` では、これまでの戻り値と計算時間を変えない。
- カーブの平行シフトは、各クーポン日の割引係数 `P(0,T)` を `exp(-shift · T)` 倍する動かし方で、既存の `curve_sensitivity$npv_per_bp` と同じ向きと定義にする。
- 引数名・列名は、rmql の命名に合わせて変えてよい。変えたときは Studio に知らせる。

## 3. 検査

1. **既存の値が変わらない**：`second_order = FALSE` と `TRUE` で、PV と1階の感応度（`sensitivity`、`curve_sensitivity`）が、従来の値と一致する。
2. **2階自動微分が差分と整合する**：クロスガンマ2つと Vanna が、PV の4点中心差分（スポットと相手の入力を同時に上下に動かす）と整合する。
3. **対称性**：`∂²/∂S∂σ` を、1階の感応度（デルタ）の中心差分、またはベガの中心差分で求めた値とも整合する。

細かい参照値・バンプ幅・許容誤差は、実装後に詰める（依頼者の指示）。

## 4. Studio 側の条件と暫定の値（参照用、最終値ではない）

Studio の `server/R/prdc_three_factor_model.R` が使う条件で、次の暫定値が出ている（rmql 0.5.0、2026-11-25）。

- ノート：想定元本 1億円、5年、年1回のクーポン `min(8%, max(0, 2% + 80% × (S / 150 − 1)))`、満期に元本を償還
- カーブ：円 1.0%〜1.8%、外貨 4.0%〜3.2%（各年の金利が1年間一定、`server/R/prdc_risk_model.R` の `PR_NOTE`）。評価日 2026-11-02
- モデル：FX スポット 150、FX ボラ 12%、円金利 Hull–White（平均回帰 0.03、ボラ 0.01）、外貨金利（平均回帰 0.05、ボラ 0.012）、相関（円・外貨 0.3、円・FX −0.2、外貨・FX 0.4）

| 項目 | 自動微分のデルタの中心差分 | PV の4点差分 | 単位 |
|---|---:|---:|---|
| クロスガンマ：スポット × 円金利 | 272.0194 | 272.0157 | 円／（FX 1円 × 1bp） |
| クロスガンマ：スポット × 外貨金利 | −396.7972 | −396.7929 | 同上 |
| Vanna：スポット × FX ボラ | −31,126.03 | −31,125.47 | 円／（FX 1円 × ボラ 1%） |

PV 103,789,643.907、FX デルタ 486,851.586、FX ベガ 44,938,625.074（円）。バンプ幅は、相関 0.001、スポット 0.15 円、ボラ 0.05%（絶対）、金利 1bp。

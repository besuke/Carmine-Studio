この並びなら、**「何が分かるかは、情報をどう得たかで決まる」**を軸にすると、確率パズルから Lean まで一本につながります。入口はモンティ・ホールがよさそうです。そこから二人の子ども、13枚のコインへ進むと、最後には読者自身が「どう観測すれば判定できるか」を考えることになります。

最初の三問は、条件を一つずつ変える

モンティ・ホール。 標準設定は、3枚の扉に車1台とヤギ2匹。司会者は車の場所を知っていて、選ばれていない扉から必ずヤギを見せ、必ず交換を提案する。このルールなら、最初にヤギを選んだ場合に交換で勝つので、交換の勝率は \(2/3\) です。司会者が事情を知らず、偶然ヤギを見せた場合はどうなるか。ここで初めて、扉の向こうに見えたものと、その扉が開けられた理由の両方が効いてきます。

二人の子ども。 各子どもの男女を独立・等確率とするパズルの設定では、「少なくとも一人が女の子である家庭」を選ぶと、二人とも女の子である確率は \(1/3\)。一方、家庭から子どもを一人無作為に選び、その子が女の子だった場合は \(1/2\) です。どちらも観測は正確です。それでも、情報を得る手順が違えば答えが変わります。さらに男女の判定に誤りがありうるなら、今度は誤判定率もベイズ計算に入ります。

13枚のコイン。 異常な1枚が重いと分かっているなら、3回で特定できます。最初に4枚対4枚を量り、傾けば重い側の4枚、釣り合えば残りの5枚に絞れます。どちらもあと2回で判定できます。

ここで「重いか軽いかも判定する」「正常と分かっている予備のコインはない」と条件を変えると、26通りの仮説に対して \(3^3=27\) 通りの結果があるのに、3回では解けません。理由は初回の天秤にあります。\(k\) 枚対 \(k\) 枚を量ると、各傾きには \(2k\) 通り、釣り合いには \(2(13-2k)\) 通りの仮説が残ります。残り2回で区別できるのは各分岐で最大9通りです。傾きの条件から \(k\le4\)、釣り合いの条件から \(k\ge5\) が必要になり、両立しません。

ここでシャノンの情報エントロピーを入れられます。26通りを等確率と置けば、初期の不確かさは \(\log_2 26\) ビット。3回の天秤の出力には最大 \(3\log_2 3=\log_2 27\) ビット分の区別があります。それでも解けないのは、天秤という道具では、初回に仮説を必要な形に分けられないからです。

Crimson Proof に入れるなら、この「13枚は3回で判定できない」を Lean で証明するところまで持っていくときれいです。天秤のルールを定義し、どんな初回の量り方でも仮説が10通り以上残る分岐があることを示す。その具体例を手にしてから、ヒルベルト、ゲーデル、チューリングで「形式化した数学に何ができるか」を広げ、カリー＝ハワードで「いま Lean が検査した証明は、どういう対象なのか」に戻れます。

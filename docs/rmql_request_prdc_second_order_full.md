# rmql への依頼：コールなし3因子 PRDC の残りの2階感応度（ガンマ・ボルガ・金利の2階・金利とボラの交差）

- 依頼元：Carmine-Studio 第15章「PRDCグリークス計算（自動微分・有限差分）」のシナリオ損益（`ui/src/content/chapters/automatic-differentiation.mdx` の「シナリオ損益：交差項」）
- 依頼日：2026-11-24
- 宛先：RiemannQL（rmql）の会話。Studio は計算を自分で書かず、rmql を呼ぶ（Studio の `CLAUDE.md`）。
- 前の依頼：`docs/rmql_request_prdc_second_order.md`（スポットとの交差の2階。実装済み、RiemannQL `b64b5e8`、`docs/spec_prdc.md` 15 章）。この依頼はその続き。

## 1. 依頼

`compute_prdc_three_factor_value()` のコールなしの閉じた式（`paths = 0`）に、スポット・FX ボラ・円カーブの平行シフト・外貨カーブの平行シフトの4変数の、**2階微分の残り**を足す。4変数の2階微分は、対称な 4×4 の行列で、独立な要素が10個ある。そのうち3個（スポット × 円カーブ、スポット × 外貨カーブ、スポット × ボラ）は実装済みで、残り7個を足す。

| 変数 | 定義 |
|---|---|
| スポット \`S\` | FX スポット（円。国内通貨建て）。小数の単位は 1 円 |
| ボラ \`σ\` | FX ボラティリティ（全区間を同じだけ動かす。小数、0.12 が 12%） |
| 円カーブ \`r_d\` | 円（国内）カーブの連続複利のゼロ金利の平行シフト（小数、0.0001 が 1bp） |
| 外貨カーブ \`r_f\` | 外貨カーブの同じ平行シフト |

| 要素（\`parameter_1\`、\`parameter_2\`） | 定義 | 表示単位（Studio が掛けて表示する） | 状態 |
|---|---|---|---|
| \`spot\`、\`domestic_curve_shift\` | ∂²V/∂S∂r_d（クロスガンマ） | 円／（FX 1円 × 1bp）、\`× 1e-4\` | 実装済み |
| \`spot\`、\`foreign_curve_shift\` | ∂²V/∂S∂r_f | 同上 | 実装済み |
| \`spot\`、\`fx_volatility\` | ∂²V/∂S∂σ（Vanna） | 円／（FX 1円 × ボラ 1 ポイント）、\`× 0.01\` | 実装済み |
| \`spot\`、\`spot\` | ∂²V/∂S²（ガンマ） | 円／（FX 1円）²、\`× 1\` | **依頼** |
| \`fx_volatility\`、\`fx_volatility\` | ∂²V/∂σ²（ボルガ） | 円／（ボラ 1 ポイント）²、\`× 1e-4\` | **依頼** |
| \`domestic_curve_shift\`、\`domestic_curve_shift\` | ∂²V/∂r_d²（円金利のコンベクシティ） | 円／（1bp）²、\`× 1e-8\` | **依頼** |
| \`foreign_curve_shift\`、\`foreign_curve_shift\` | ∂²V/∂r_f² | 同上 | **依頼** |
| \`domestic_curve_shift\`、\`foreign_curve_shift\` | ∂²V/∂r_d∂r_f | 円／（1bp × 1bp）、\`× 1e-8\` | **依頼** |
| \`domestic_curve_shift\`、\`fx_volatility\` | ∂²V/∂r_d∂σ | 円／（1bp × ボラ 1 ポイント）、\`× 1e-6\` | **依頼** |
| \`foreign_curve_shift\`、\`fx_volatility\` | ∂²V/∂r_f∂σ | 同上 | **依頼** |

- 値は、これまでと同じく、**2階自動微分**（閉じた式を \`Operand\` について総称的に書いた式の上で、デルタなどの逆伝播を記録してもう一度微分する）で求める。差分ではない。
- rmql の戻り値は、小数・1円・カーブの平行シフトの単位のままでよい。単位の換算は Studio が行う。
- 範囲：コールなし、ターゲット償還なし、ノックアウトなしの閉じた式だけ。モンテカルロやコール付きは対象外。
- 目的：Studio のシナリオ損益は、いま「一次近似」と「一次近似＋交差項3つ」を、フル再評価と並べている。フル再評価との差には、残りの2階の項が入っている。全部の2階が取れれば、**2次のテイラー展開**（ΔV ≈ Σ g_i Δ_i + ½ Σ_i Σ_j H_ij Δ_i Δ_j）を完成させ、残りを3次以上として見せられる。ガンマ、ボルガ、金利のコンベクシティも、そのまま標準のグリークスとして表示できる。

## 2. 戻り値の形（案）

\`second_order\` の引数を、\`FALSE\`／\`TRUE\`／\`"full"\` にする。

- \`FALSE\`（既定）：これまでと同じ（\`second_order\` の表なし）。
- \`TRUE\`：これまでと同じ。\`second_order\` は3行（スポットとの交差）で、**行の順序と値を変えない**（Studio がすでにこの形を読んでいる）。
- \`"full"\`：\`second_order\` が10行。先頭の3行は \`TRUE\` と同じ行・同じ順序・同じ値で、その後に残りの7行を、上の表の順（\`spot\` × \`spot\`、\`fx_volatility\` × \`fx_volatility\`、\`domestic_curve_shift\` × \`domestic_curve_shift\`、\`foreign_curve_shift\` × \`foreign_curve_shift\`、\`domestic_curve_shift\` × \`foreign_curve_shift\`、\`domestic_curve_shift\` × \`fx_volatility\`、\`foreign_curve_shift\` × \`fx_volatility\`）で足す。

- 行は、\`parameter_1\` と \`parameter_2\` の**組**で見分ける（同じ \`parameter_2\` が複数の行に出る）。混合微分は対称なので、各組は1行だけ。
- 列は \`parameter_1\`、\`parameter_2\`、\`d2_npv\`。名前は、rmql の命名に合わせて変えてよい。変えたときは Studio に知らせる。
- コール、ターゲット償還、ノックアウトと一緒に指定したときは、\`TRUE\` と同じくエラー。

## 3. 検査

1. **既存の値が変わらない**：\`second_order = FALSE\`、\`TRUE\`、\`"full"\` で、PV と1階の感応度（\`sensitivity\`、\`curve_sensitivity\`）が従来の値と一致する。\`"full"\` の先頭の3行が \`TRUE\` の3行と同じ。
2. **10要素が有限差分と整合する**：PV の有限差分（対角は3点の2階差分、非対角は4点の差分）と整合する。
3. **対称性**：非対角の要素を、微分の順序を入れ替えた計算（たとえば、デルタをボラで微分したものと、ベガをスポットで微分したもの）と比べて一致する。
4. **2次のテイラー展開の整合**：小さな動きで、ΔV − （一次 ＋ ½ × 2階）の残りが、動きを半分にすると約 1/8 になる（3次の誤差）。
5. **独立な値との比較**：金利のボラ（Hull–White の σ）をゼロにしたとき、3因子の閉じた式は1因子のノート（\`docs/spec_prdc.md\` 5 章、\`V(T) = σ_X² T\`）に一致する。このとき、ガンマとボルガが、1因子の閉じた式（各クーポンがコールスプレッド）の2階微分（Black の式のガンマ・ボルガ）と一致する。

細かい参照値・バンプ幅・許容誤差は、実装後に詰める（依頼者の指示）。
